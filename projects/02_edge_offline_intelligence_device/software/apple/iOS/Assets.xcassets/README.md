# Local Voice app icon

`AppIcon.appiconset/AppIcon.png` is the opaque, 1024 × 1024 iOS app icon. Apple applies the outer icon shape. Generated September 12, 2026 using Codex's built-in image generation tool, then normalized to Apple's required raster dimensions. No input/reference image was used. The source generation was visually checked for the speech bubble, waveform, legibility, and absence of text or extra marks. This is design work, not experimental evidence.

## Generation prompt

Use case: logo-brand. Asset type: final iOS app icon for the Local Voice app, a private on-device English voice assistant. Create a polished 1024 by 1024 square raster icon: a centered, bold, simple ivory speech bubble containing a short five-bar emerald audio waveform, on a rich near-black charcoal background. Subtle dimensional lighting, exceptionally clean silhouette, generous safe margin, legible at very small sizes. Fill the entire square canvas with opaque background; no pre-rounded outer corners. No text, no letters, no numbers, no watermark, no devices, no extra symbols, no scene or mockup. Deliver a single icon only.
