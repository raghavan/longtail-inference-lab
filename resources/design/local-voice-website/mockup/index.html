How the pieces cooperate

One controller.
A deliberate sequence.

Control

The button runs the turn.

The Python controller coordinates recording, transcription, generation, synthesis, and playback. It sends state updates back to the button’s LED. A press during processing or playback cancels the active turn.

Compute

Two models. Different jobs.

Whisper tiny.en converts audio to text. Qwen2.5 1.5B Instruct uses that transcript and a fixed system prompt to produce a short answer. The CUDA profile runs recognition and all 29 answer-model layers on the GPU. eSpeak synthesis stays on CPU.

Boundaries

A fresh start, each time.

The current device handles English, one question at a time. There is no conversation history, web search, document retrieval, or cloud fallback. Temporary audio is cleaned up on normal completion, cancellation, and ordinary errors.

Read the runtime and privacy details +

The answer context is 2,048 tokens, with a default 128-token response cap. A response that exhausts its allowance is discarded rather than spoken partially. Runtime commits, model revisions, and SHA-256 hashes are pinned in the runtime lock.

Initial setup downloads software and weights. The deployed service’s process network namespace contains only loopback; this is a boundary around the service, not a claim that the entire board has no network. Temporary audio uses RAM-backed storage. Abrupt process kills and operating-system behavior have separate retention limits; no forensic-erasure guarantee is made.

A work in progress

From an idea
to something you can hold.

Local Voice is a local speech-and-answer project from Long Tail Inference Lab. The hardware story above preserves the enclosure concept while the working prototype develops on an open, mains-powered board.

The first build uses a Jetson Orin Nano Super, a USB microphone and speaker, a physical button, and mains power. The standalone button-to-spoken-answer loop works with the laptop disconnected. GPU transcription and answering have passed basic checks.

The illustrations simplify the components. The final enclosure and cable routing are conceptual; a screen, battery, and portable enclosure are deferred. The first-year ceiling is $1,000, including required new hardware, software, distribution fees, tax, and shipping. Scored quality, sustained reliability, and cross-platform evaluation remain open.
